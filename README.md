# 기억의 조각 (Fragments of Memory)

문장을 기억했다가 다시 적고, 그림을 봤다가 물건이 어디에 있었는지 찾아내는 기억력 앱.

- React 19 + Vite + TypeScript + Tailwind CSS
- 서버·외부 API 없음 (정적 사이트, 진행 상황은 브라우저 localStorage)
- Vercel: Framework Preset `Vite`, Build `npm run build`, Output `dist`, 환경 변수 불필요
